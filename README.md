# Advice Generator

A web application that delivers curated advice through a clean and interactive interface, designed with a focus on usability, responsiveness, and smooth user interactions.

The project uses a local data source to provide a consistent experience while keeping the application lightweight and independent of external APIs.

## Website

**Live Demo:**  
https://nikolozwdev.github.io/Advice-Generator/

## About

Advice Generator was built as a frontend project centered around dynamic content rendering and interactive user experience.

Users can generate new advice, browse previously viewed entries through the built-in history, and quickly copy or share quotes. The application is designed to provide fast interactions with a simple and distraction-free interface.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Running Locally

Clone the repository:

```bash
git clone https://github.com/NikolozWDev/advice-generator.git
```

Move into the project directory:

```bash
cd advice-generator
```

Open `index.html` in your preferred browser.
